## 附：怎么采集这些数据

```bash
# 1. 记录 obs / action（ros2 bag）
ros2 bag record /joint_states /imu /action /cmd_vel -o ~/bags/$(date +%Y%m%d_%H%M)

# 2. onnx 哈希
sha256sum robots/<robot>/models/policy.onnx

# 3. 导出 screen 日志
screen -r inference_node -X hardcopy /tmp/inference_log_$(date +%Y%m%d).txt

# 4. 部署侧配置
cp robots/<robot>/configs/<policy>.yaml ~/records/

# 5. 同种子仿真回放
# （在训练机上，用相同的 seed 跑一次 eval --render-mode record）
```
